# AI Limits for macOS

Нативный desktop-виджет для отображения лимитов Codex и Claude.

## Скачать и установить

1. Скачайте [`AI-Limits-macOS-universal.zip`](Releases/AI-Limits-macOS-universal.zip).
2. Распакуйте архив и перенесите `AI Limits.app` в папку `Программы` (`Applications`).
3. При первом запуске нажмите приложение правой кнопкой мыши, выберите **Открыть** и подтвердите запуск.

Готовая сборка подходит для Mac с Apple Silicon и Intel и требует macOS 13 или новее.

Для отображения данных пользователь должен войти в собственные аккаунты Codex и Claude Code. Учётные данные в архив не входят.

## Возможности

- лимиты Codex и Claude за 5 часов и неделю;
- автоматическое обновление каждые 2 минуты;
- перемещение виджета с сохранением позиции;
- управление через строку меню.

## Сборка из исходников

```bash
./build.sh
```

Собранное приложение появится в `build/AI Limits.app`.
